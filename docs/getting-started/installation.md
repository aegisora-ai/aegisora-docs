# Installation

Aegisora is maintained as an open-source repository with a pnpm-based developer workflow.

## Requirements

| Tool | Baseline |
| --- | --- |
| Node.js | 24.x |
| pnpm | 11.20.0 |
| Git | Current |
| Aegisora | v0.1.2 |

## Clone

``bash
git clone https://github.com/aegisora-ai/aegisora.git
cd aegisora
``
